# Clipped Motions site

Public static pages for Clipped Motions, used as the home, Terms of Service, Privacy Policy, and OAuth redirect URLs for Clipped Motions Hub (TikTok and Meta app forms).

The Terms of Service and Privacy Policy are a plain-language template written for this site and the Hub. They are not legal advice.

## Pages

- `/` — home
- `/terms.html` — Terms of Service
- `/privacy.html` — Privacy Policy
- `/tiktok/callback/` — TikTok OAuth redirect (forwards the query string to the local Hub)
- `/meta/callback/` — Meta OAuth redirect (forwards the query string to the local Hub)

Static HTML and CSS only. No third-party scripts, analytics, cookies, or forms.

GitHub Pages is served from the `main` branch root.
